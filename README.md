# Deng Xu · EmbeddedNote

Embedded engineering, written down so it can be checked. I run
[EmbeddedNote](https://embeddednote.com/), a bilingual journal about e-paper,
low-power wireless and the hardware around them, and Datadelta, which supplies
the panels and modules those notes are written about.

## What is published

- **[E-paper panel selection table](https://embeddednote.com/en/e-paper/selection/)** — 40 E5, E6 and Kaleido 3 panels with active area, resolution and packed frame size. Also a citable dataset: [doi.org/10.5281/zenodo.24297081](https://doi.org/10.5281/zenodo.24297081) (CC BY 4.0).
- **[E-paper image converter](https://embeddednote.com/en/tools/epaper-image-converter/)** — palette mapping, dithering, RAW4 export, runs in the browser.
- **[BLE throughput planner](https://embeddednote.com/en/tools/ble-throughput-calculator/)** — airtime and wall-clock estimates with every assumption on the page.
- **[Engineering notes](https://embeddednote.com/en/e-paper/)** — waveform, ghosting, partial refresh, power budgets, panel selection.

## How the numbers work

Every figure on the site is either calculated from a stated formula, quoted from
the document that defines it, or labelled as unverified. Measurements that were
not taken are not claimed. That rule is why the articles list their assumptions
before their conclusions.
